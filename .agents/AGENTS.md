# .agents/

Agent-agnostic harness configuration, following the
[agent-agnostic repository layout](https://agentskills.io): portable assets
live here as the single canonical copy and are symlinked into per-harness
directories; generated assets are rendered by their tool; agent-specific
assets stay in their native directories.

## Layout

- `skills/` — canonical OpenSpec workflow skills (generated by
  `openspec init`, CLI-managed, committed). `.claude/skills/`,
  `.opencode/skills/`, and `.omp/skills/` are symlinks into this directory.
  The `.openspec-target` marker records that the OpenSpec CLI manages this
  directory for Codex.
- `scripts/` — sync/validation scripts for the layout.

## Classification

| Asset | Category | Source of truth |
| --- | --- | --- |
| `skills/*/SKILL.md` | Portable | this directory (symlinked elsewhere) |
| `.claude/commands/opsx/`, `.opencode/commands/`, `.omp/commands/` | Generated | the `openspec` CLI (`openspec init` / `openspec update`) |
| `AGENTS.md` (repo root) | Portable | itself |
| `CLAUDE.md` (repo root) | Pointer | `@AGENTS.md` |
| MCP configuration | Not applicable | none in this repo |

Per-harness command files differ legitimately (frontmatter, invocation
spelling, `$ARGUMENTS` vs `$@` argument interpolation) — they are rendered
output, not portable copies.

## Rules

- Never edit a skill through `.claude/skills/`, `.opencode/skills/`, or
  `.omp/skills/` — they are symlinks; edit the canonical `.agents/skills/`.
- Never hand-edit the generated command files; regenerate with
  `openspec update`.
- After `openspec init` or `openspec update` (update writes through the
  symlinks and may leave a harness-flavored invocation spelling in the
  canonical copy; init recreates real files), re-run
  `.agents/scripts/link-agent-skills.sh` and commit the result.

## Adding or refreshing workflow skills

1. Run `openspec update` (or `openspec init --tools claude,codex,opencode,oh-my-pi`).
2. Run `.agents/scripts/link-agent-skills.sh` to restore the symlink layout.
3. Commit the canonical `.agents/skills/` content, the symlinks, and any
   regenerated command files together.
